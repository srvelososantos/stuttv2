<h1>Stutt</h1>

<p>O Stutt é um sistema web completo desenvolvido com Vue.js no front-end e NestJS no back-end.
A aplicação integra serviços de armazenamento na AWS S3, autenticação baseada em JWT, e um microserviço de Text-to-Speech em Python para geração de áudio a partir de documentos PDF.</p>

<p>
   Principais funcionalidades

 - Upload de arquivos PDF com armazenamento seguro em bucket AWS.

 - Conversão de PDFs em arquivos de áudio utilizando microserviço Python (TTS).

 - Interface web responsiva desenvolvida em Vue.js.

 - Backend escalável em NestJS com arquitetura modular.

 - Autenticação e autorização via JWT.

 - Organização de arquivos por usuário (isolamento de dados).
</p>

<p>
   Arquitetura do projeto

 - Front-end: Vue.js + Axios

 - Back-end: NestJS (TypeScript)

 - Microserviço: Python + Text-to-Speech

 - Storage: AWS S3

 - Autenticação: JWT
</p>

<p>
  O projeto foi criado para facilitar o consumo de conteúdo em PDF por meio de áudio, oferecendo uma solução moderna, escalável e acessível para estudantes, profissionais e usuários em geral.
</p>
